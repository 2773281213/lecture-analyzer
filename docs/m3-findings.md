# M3 验收记录

> 2026-10-15。工具是通用的：病毒学（韩语授课、现场中文翻译、韩语笔记、中文课件）、药理学（中文授课、中文课件）、微生物（老师不提供课件）只是验收样例。模拟题是自制的样例，不是老师提供的资料。费用按各模型官方单价估算，以中转站实际计费为准。

## 1. 语言通用化与书库迁移

- 书库从 v2 升级到 v3，升级前自动备份为 `lecture.db.bak-v2`。病毒学的旧写法 `ko+zh` 换算为"授课 ko、现场翻译成 zh"，课程列表显示"老师用韩语授课，现场有人翻译成中文"；三门课的课件选择都是"未选择"。
- 单元测试覆盖了其他语言组合：英语 + 法语混用、日语授课翻译成中文、名称表里没有的语言（如 sw，直接显示代码）、地区代码（zh-tw）；本地转写对模型不支持的语言自动改为识别语种，不报错。
- 回顾线索词表按课程语言取（中、韩、英、日），没有词表的语言照常运行。

## 10. 发现的问题与改进

- **流式读到一半断开**：识别病毒学课件时，一次请求在流式读取途中连接被断开（`APIConnectionError`），SDK 不会自动重试，异常直接抛出，后面 4 章没有识别。改进：
  - 流式请求读到一半断开时整体重发，最多重试 2 次（间隔 3 秒、10 秒），Claude 和 OpenAI 兼容接口都适用；
  - 各家 SDK 的接口错误统一转成可读的说明，命令行不再打印堆栈；
  - 一次处理多份资料时，一份失败不影响其余资料，最后汇总；已识别的页都已保存，`lec material process` 接着做。
- **流式读到一半断开（Claude）**：网页上的一次报告任务里，Claude 的流式响应被中转站中途断开，SDK 直接抛出 httpx 的 `RemoteProtocolError`（没有包装成自己的连接错误），重试没有接住。改进：httpx 的传输错误也按连接中断重试（Claude 和 OpenAI 兼容接口），测试覆盖了这个异常。这次报告照常生成，只是注明"叙述部分没有生成"，降级处理按设计生效。
- **叙述字段为空**：第一次报告的"复习建议"是空字符串。改进：总体判断、题型预测、复习建议有空的，指出缺的部分让模型补写一次；修复后生成的第 3 份报告叙述完整（第 2 份因上一条的断线没有叙述）。
- **"不考"判得太宽**：老师说"不用每种病毒都背""昆虫病毒不讲"（强度 1–2），原规则把整个知识点判为"不考"并清零，其中一个知识点还有两条"强调"。改进：只有明确说不考（强度 3）或考试通知写明不考，才整体排除；较弱的"不考"只扣分（权重 −1 × 强度），照常列在"考试范围"里；总复习的星级用同一条规则；整理笔记的提示词说明了"不考"信号的强度怎么定（只影响以后整理的笔记）。
