## 课程书架 v0.3.0：新界面，六种主题

下载 `LectureAnalyzer-Setup-0.3.0.exe` 安装（按用户安装，不需要管理员权限）。从旧版本升级时直接覆盖安装，书库和设置都会保留。

### 新界面：工作台布局

以前的界面只有顶部一条栏和中间一列内容，课程、讲次、笔记、播放器挤在同一页里。这版改成"工作台"：最左边一列窄导航栏，接着是侧栏（当前页面的目录），中间是内容，右边是详情栏，最下面一行状态栏。

- **导航栏**：书架；进入课程后有课程、复习、提问；还有任务；底部是侧栏开关、主题和设置。
- **书架首页**：课程列表直接显示每门课的处理进度、复习进度和下一步该做什么，右栏是选中课程的概况；想看书脊卡片的样子，点一下就能切回原来的书脊视图。
- **课程页**：侧栏是课程各部分的目录（讲次、课程资料、考试方案、考前分析、知识点体系），滚动时标出当前所在的部分；讲次从长列表改成表格，可以按状态筛选；右栏显示选中那一讲的处理流程和它已经有的文件。
- **讲的阅读页**：播放器和转写都移到右栏，转写可以跟随播放滚动；新增一条时间轴，标出考点信号的位置和各知识点所占的时段，点一下直接跳过去；正在播放的知识点在笔记、目录和时间轴上同时标出；侧栏有上一讲 / 下一讲。
- **其余页面**：总复习、提问、考前报告、课程资料、设置、后台任务都接到同一套侧栏，出错页也在新布局里。

### 六种主题

- **六种配色**：纸墨 · 书房（默认）、云母 · Windows 11、素白 · 荧光笔、书院 · 墨绿金、夜读 · 深色台灯、极光 · 毛玻璃。六种是同一套布局、不同的配色变量，切换不影响数据。
- **怎么切换**：导航栏左下角的「主题」、状态栏右下角，或设置页「外观」里的六张预览卡片，点一下立刻生效。
- **两个开关**：可以打开"系统深色模式时用「夜读」"（默认开，和原来的跟随系统深色模式一致）；"毛玻璃效果"只影响极光主题，核显或较慢的电脑可以关掉。
- **选择会记住**：界面偏好存在本机，桌面程序每次启动端口不同也能记住，下次打开照样生效。

### 顺手修好的桌面问题

0.2.2 当时没有单独发布，这些修正本版一并带上：

- **选择文件、选择文件夹不再偶发闪退**：此前在网页里点选文件或文件夹时，文件对话框在后台线程里直接打开，Windows 下偶发原生异常导致书架窗口直接退出；现在统一回到界面主线程打开对话框。
- **首次设置完成后切换页面不再记下回调错误**：新建或打开已有书库时，等设置页收到返回结果后再跳转到书架，不再因页面先切换导致 `desktop.log` 记录 `JavascriptException`。
- **关闭窗口不再报临时目录清理错误**：WebView2 改用固定的本地数据目录（`%APPDATA%\LectureAnalyzer\webview`），不再每次在 `%TEMP%` 创建无痕临时目录，避免关闭窗口时与浏览器子进程退出顺序竞态报错及残留临时文件夹，窗口启动也更快。
- **消除本机连接断开的日志噪音**：桌面程序的本机网页服务改用 `SelectorEventLoop`，页面跳转或关窗断开连接时不再向 `desktop.log` 打印 `ConnectionResetError: [WinError 10054]`。

### 升级后

- 主题、书架视图（表格 / 书脊）、侧栏是否显示属于新增的界面偏好，第一次打开用默认值（纸墨、表格、显示侧栏）。
- 书库、笔记、课程记忆、总复习、考前报告、问答都不需要迁移，数据库版本没变。
- 下载按钮和菜单不变；命令行（`lec models`、`lec run 课程名`……）与上一版相同。
