## 课程书架 v0.3.1：转写不再因为上游内容审核而整讲失败

下载 `LectureAnalyzer-Setup-0.3.1.exe` 安装（按用户安装，不需要管理员权限）。从旧版本升级时直接覆盖安装，书库和设置都会保留。

### 修正

- **一片被内容审核拦下，不再整讲转写失败**：用能听音频的大模型转写（`[asr] backend = "llm"`）时，上游偶尔会在请求阶段直接拒绝一次调用——例如 Gemini 对医学、生物学内容常返回 `This request was blocked by Gemini's filters`。以前这种错误被当成普通的请求失败，一路抛到任务层：整讲转写中断，既不会把音频切小重试，也不会交给本地模型补转。
  现在它和「返回了拦截说明」一样按**被拦截**处理，走原来的流程：把这一片对半切开重试（最短切到 2.5 分钟）→ 仍被拦就换备用型号 → 都失败才记下这一段，用本地模型补转、并在页面上说明。

### 说明

- 只影响转写。整理笔记、考前报告等文字步骤如果被上游拦下，仍然会如实报错，不会悄悄降级。
- 拦截是上游按内容判断的，同一段音频原样重发仍会被拦——所以是切小，而不是重试。
- 实测（药理学第 8 讲第 1 节第 1 片，10 分钟）：整片被拦 → 切成两个 5 分钟仍有一半被拦 → 再切成四个 2.5 分钟全部转写成功，139 句、没有跳过区间、93 秒完成。
- 被拦截的请求没有产生用量，不额外计费。
