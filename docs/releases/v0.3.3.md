## 课程书架 v0.3.3：模型拒答时自动换下一个模型

下载 `LectureAnalyzer-Setup-0.3.3.exe` 安装（按用户安装，不需要管理员权限）。从旧版本升级时直接覆盖安装，书库和设置都会保留。

### 新增

- **模型拒答时自动换下一个模型，任务不再中断**：整理课程记忆、总复习、问答、考前报告、考试方案这些步骤用的是 Claude 时，偶尔会遇到模型按自己的安全策略拒绝作答（例如病毒学第 4 讲，模型给的分类是 `bio`）。以前这一步直接失败、整个任务停下来；现在会**自动改用备用模型重跑同一次请求**，页面上按实际作答的模型显示处理说明和费用。
- **怎么配**：在 `config.toml` 的模型档案里加一行，例如

  ```toml
  [models.claude.options]
  fallback = "gpt"        # 这个档案拒答时改用「gpt」档案重跑
  ```

  备用档案自己也可以再配 `fallback`，最多三层。设置页的「各步骤用的模型」不用改。
- 只有**模型自己拒绝作答**才换模型；**输入被上游内容审核过滤**（例如 Gemini 拦下音频）不换——那种要换内容或切小，转写仍是原来的「切小重试 + 本地模型补转」。

### 界面

- **讲的阅读页：考点信号更醒目**：考点信号移到这一讲内容的最前面，只显示重点和例题的那几条；每条信号里的知识点直接链到本讲对应的知识点，方便对照着看。

### 说明

- 用量按两家之和记录：被拒答的那次请求消耗的输入也算进去，费用表按实际作答的档案计。
- Anthropic 有服务端的拒答回退，但只在直连官方接口时可用，走中转站时用不了；这一版在客户端补上了同样的效果，对所有接入方式都有效。
- 实测（病毒学第 4 讲「巴尔的摩分类法与动物细胞及病毒培养」）：同一份输入原样重发两次都被拒、加一句"这是课堂笔记整理"也被拒；换成备用档案一次通过，6 个知识点映射、2 条跨讲联系。把这份笔记拆成 15 条单独发则条条都能通过——是整段累计触发的，不是某一句有问题。
- 这类拒答与课程内容有关（病毒培养、细胞传代、致癌基因这类医学生物学内容），不是笔记写错了，也不影响转写和整理笔记这两步（它们走 Gemini）。
