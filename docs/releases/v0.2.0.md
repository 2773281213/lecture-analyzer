## 课程书架 v0.2.0：先定考试方案，再分析知识点

下载 `LectureAnalyzer-Setup-0.2.0.exe` 安装（按用户安装，不需要管理员权限）。从旧版本升级时直接覆盖安装，书库和设置都会保留（书库升级前自动备份为 `lecture.db.bak-v4`）。

### 新功能：考试方案
- **先弄清这门课怎么考**：第一讲转写完后，自动分析这门课的考核方式、成绩构成、**题型及分值分布**、**老师规定的答题方向**和考试范围。来源包括第一讲里讲考试的部分、你填写的老师考试说明（最优先）、已导入的考试通知 / 复习提纲，以及往年试题的题型统计。
- **停下来让你确认**：分析结果显示在课程页的「考试方案」卡片里，每一条都附出处（老师原话可以点开听录音，核对不上的会标出来）。题型、题数、每题分值可以逐行修改、增删，合计和占比自动计算。确认后才接着整理笔记；不需要时可以跳过。
- **之后的分析都按方案来**：
  - 整理笔记：标出每个知识点适合出成哪些题型，分值占比高的题型对应的内容记得更细；
  - 总复习：按题型和答题要求写要点（名词解释写成定义、简答写成分点、论述写成提纲、病例分析写出依据和治疗）；
  - 打分：新增「题型匹配」加分；
  - 考前报告：先列题型分值表和答题要求，再**按题型分组**列出候选考点（仍是多个模型排名后合并）；
  - 问答：问到"这道题怎么答"时按答题要求组织答案。
- 命令行：`lec plan show / analyze / confirm / skip 课程名`。

### 升级后
- 已有课程的考试方案为「未设置」：已处理完的讲不受影响。在课程页点「分析考试方案」，或下次处理新的讲时会自动分析并停下等你确认。
- 确认方案后，已经整理过笔记的讲会自动按方案从「整理笔记」起重新处理（不重新转写；课程页会提示大约要调用几次模型）。
- 新配置项见 `config.example.toml` 的 `[exam_plan]`（如 `auto_confirm = true` 可以不停下来确认）；`[steps]` 里不写 `exam_plan` 时用整理笔记的模型。
